# Security Policy

## Supported Versions

The following versions of this project are currently supported with security updates.

| Version | Supported | Notes |
| ------- | --------- | ----- |
| 5.5.x   | :white_check_mark: | Current stable release |
| 5.4.x   | :white_check_mark: | Security fixes only |
| 5.3.x   | :warning: | Critical fixes only |
| < 5.3   | :x: | No longer supported |

If you are running an unsupported version, we strongly recommend upgrading to the latest supported release as soon as possible.

## Reporting a Vulnerability

If you believe you have found a security vulnerability in this project, please report it privately and responsibly.

Please do not disclose the issue publicly until we have had a chance to investigate and remediate it.

### Preferred method

Please email us at:

emmanucheru@gmail.com

If you are using GitHub and prefer a private report flow, please open a confidential vulnerability report through the repository's security advisories feature if enabled.

### Information to include

When reporting, please include:
- a description of the vulnerability
- affected version(s)
- steps to reproduce
- potential impact
- any suggested remediation or mitigation

### Response expectations

We aim to acknowledge receipt within 48 hours and provide an initial assessment within 5 business days. We will keep you informed as we investigate and work toward a fix.

### Disclosure policy

- We will review and validate the report
- We may request additional information
- If the issue is accepted, we will work on a fix and coordinate disclosure
- If the issue is declined, we will explain the reason and any next steps

We appreciate responsible disclosure and will do our best to address valid security issues promptly.
